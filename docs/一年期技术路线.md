# 空地一体化森林碳汇监测系统：一年期技术路线

## 项目主线

项目方向保持为“基于无人机航拍图像的空地一体化森林碳汇监测系统”。视觉识别只是空中遥感模块，最终系统由无人机影像、STM32 地面监测终端、空地数据融合、碳储量/碳汇估算和可视化平台共同构成。

## 系统模块

1. 地面监测：采集温度、湿度、CO₂、光照和土壤湿度，通过 ESP8266 上传。
2. 空中监测：采集无人机 RGB 或多光谱影像，完成植被分类、覆盖度计算和植被参数提取。
3. 估算模型：先完成碳储量估算；获得多时相数据后，再计算碳储量变化并分析碳汇。
4. 数据融合：对同一区域、相近时间的航拍结果与地面传感器数据进行匹配和校正。
5. 可视化：展示传感器数据、植被分布、覆盖度、估算结果和历史记录。

## 一年期阶段安排

### 第 1—2 月：完成最小闭环

- 明确研究区、无人机相机类型和地面传感器型号。
- 确定统一的设备编号、区域编号、采集时间和数据格式。
- 打通“模拟传感器数据上传—数据库保存—网页查询”链路。
- 采集第一批校园林地航拍图像。

### 第 3—5 月：数据集与基线模型

- 制作植被分割数据集，统一树木、草地、裸地和其他区域的标注规范。
- 训练基线模型，记录 Precision、Recall、mIoU、mAP、参数量和推理速度。
- 实现植被覆盖度和各类别面积占比计算。

### 第 6—8 月：论文实验与碳储量估算

- 确定一个可验证的模型或融合方法改进点。
- 完成对比实验、消融实验和误差分析。
- 采集样地测量数据，建立生物量/碳储量估算关系。
- 比较空中数据单独估算与空地数据融合估算的差异。

### 第 9—10 月：系统集成

- 接入真实 STM32/ESP8266 数据。
- 将植被分析、覆盖度和碳储量结果接入网页。
- 完成历史数据、结果导出、异常处理和实地测试。

### 第 11—12 月：成果固化

- 完成论文、结题报告、实验数据和演示视频。
- 整理软件著作权源代码与说明书。
- 根据实体终端结构准备实用新型专利；根据数据融合创新程度评估发明专利。

## 预期成果

- 空地一体化监测原型系统 1 套。
- 校园林地航拍与地面监测数据集 1 套。
- 学术论文 1 篇。
- 软件著作权 1 项。
- 实用新型专利 1 项，具备明确算法创新时追加发明专利。
- 完整结题报告、测试报告、用户手册和演示视频。

- 已完成通用图像检测、摄像头检测和视觉 API。
- 已完成 Vue 演示页面及图像上传/摄像头拍照识别。
- 已建立地面传感器数据上传、查询和 SQLite 持久化接口。
- 下一步：用模拟数据验证地面数据链路，然后确定真实硬件数据格式。
