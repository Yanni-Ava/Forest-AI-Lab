# 空地一体化森林碳汇监测系统：AI技术路线

## 1. AI模块定位

AI模块服务于原大创“基于无人机航拍图像的空地一体化森林碳汇监测系统”，负责空中影像处理、植被参数提取和模型实验，不替代STM32地面监测、数据融合和Web展示模块。

## 2. 输入与输出

### 输入

- 无人机RGB航拍图像；如后续获得多光谱相机，再增加红光和近红外波段。
- 成员A提供的树木、草地、裸地和其他区域分割标注。
- 系统联调阶段由成员B提供的地面环境数据接口。

### 输出

- 植被分割掩膜与叠加效果图。
- 树木、草地、裸地及其他区域面积占比。
- 总植被覆盖度。
- 模型推理时间、置信度和实验指标。
- 供Web系统调用的标准JSON结果。

## 3. 分阶段模型路线

1. **流程基线**：使用RGB Excess Green（ExG）提取绿色植被，验证读取、处理、统计和保存流程。
2. **模型基线V1**：使用Ultralytics YOLO分割模型训练 `tree / grass / bare_land / other` 数据集。
3. **模型选择门禁**：先用20—50张试标图比较YOLO实例分割与语义分割标注/输出是否匹配。树冠等独立对象可使用实例分割；草地、裸地等连续地表覆盖更适合语义分割。根据试标结果再确定论文主模型，不能只因当前已安装YOLO就锁定最终方案。
4. **模型优化V2**：针对阴影、小树冠和复杂背景选择一个可验证改进点，完成对比实验与消融实验。
5. **系统集成**：导出稳定权重，通过FastAPI向Web模块提供分割结果与覆盖率。
6. **空地融合**：将影像结果与相近时间、同一区域的地面监测数据匹配，支持后续碳储量估算。

## 4. 评价指标

- 分割模型：Precision、Recall、mAP50、mAP50-95、Mask IoU或mIoU。
- 工程性能：参数量、模型文件大小、单张推理时间、失败率。
- 应用指标：植被覆盖度绝对误差；有样地真值时记录碳储量估算误差。

## 5. 关键技术边界

- 普通RGB相机不能直接计算标准NDVI；只有红光和近红外波段齐全时才使用NDVI表述。
- 单期航拍数据主要支持碳储量估算；碳汇变化需要多时相观测。
- 当前通用YOLO目标检测结果只证明环境和调用链正常，不代表森林植被模型效果。
- ExG结果是无训练基线，不作为最终论文模型精度结论。

## 7. 近期验收标准

- 环境能根据固定依赖重新安装并通过版本检查。
- 至少完成一张森林主题图片的RGB植被流程演示。
- 建立统一数据集目录、类别和标注规则。
- 每次实验具备参数、结果、指标、局限和复现命令。
- `dataset_v1` 到位后可以直接开始分割模型V1训练。
