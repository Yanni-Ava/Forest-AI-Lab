# 软件著作权与专利准备清单

## 软件著作权

建议软件名称暂定为“空地一体化森林碳汇监测与可视化系统 V1.0”。正式申请前核对名称重复风险和学校署名要求。

持续保留：

- 完整源代码及统一版权头。
- 软件功能结构、流程图、数据库与接口说明。
- 登录、数据采集、影像分析、结果展示和报表等界面截图。
- 安装部署手册、用户操作手册和版本记录。
- 代码页数、完成日期、开发方式和权利归属证明。

软著保护的是软件表达和代码，不等于证明算法具有学术创新。

## 实用新型专利候选

候选方向：用于小尺度林地碳汇监测的模块化地面监测终端。必须形成明确的实体结构、连接关系、防护、供电和安装设计，不能只写功能。

准备材料：结构图、模块连接图、实物照片、部件名称、工作过程、区别于常见环境监测终端的结构特征。

## 发明专利候选

候选方向：无人机植被参数与地面环境数据的时空匹配、动态融合和误差校正方法。

正式撰写前必须完成现有技术检索，并用实验说明技术效果。仅把常见分割、传感器和加权平均拼接起来，通常不足以形成稳定的创造性基础。

## 时间要求

- 论文公开、答辩展示或代码公开前，先与导师和学校成果管理部门确认专利申请顺序。
- 不在没有检索、没有真实结构或没有实验效果的情况下仓促提交。
- 发明人、著作权人、论文作者和成员贡献记录应保持一致、可解释。
