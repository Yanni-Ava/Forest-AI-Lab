## 四、模型替换判断

Alpha V0.5 只有同时满足以下条件，才建议替换当前 Demo 主模型：

1. 默认预测阈值下能稳定输出结果。
2. 结果图没有明显大面积乱检。
3. Mask mAP50 或可视化效果优于当前 Demo。
4. 对校园/森林图片更贴合项目场景。
5. API 和 Web 页面测试通过。

如果不满足，处理方式是：

```text
保留当前 Demo 主模型；
Alpha V0.5 作为实验模型记录；
继续补数据和修标。
```
