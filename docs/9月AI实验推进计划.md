# 9月AI实验推进计划

## 阶段目标

9月目标是把8月完成的AI Demo升级为可复现实验流程，形成AI模块V2的基础。

核心闭环：

```text
数据集 -> 批量实验 -> 指标记录 -> 结果图片 -> Web/API展示 -> 阶段总结
```

## 负责人任务

负责人：王思丹  
职责：AI算法与项目管理

1. 建立可复现实验流程
   - 使用 `AI/run_batch_experiment.py` 批量处理图片。
   - 每次实验输出 `summary.csv`、`details.json`、检测结果图和植被覆盖率图。
   - 统一实验编号，例如 `EXP-20260902-BATCH-V1`。

2. 完成森林图片识别实验
   - 若 `dataset_v1` 未到位，先使用现有森林/植被样例图验证流程。
   - 若 `dataset_v1` 到位，优先对 `images/test` 或 `sample` 跑批量实验。
   - 记录通用YOLO模型的局限，避免把它写成森林专用模型。

3. 建立评价指标记录
   - 检测任务记录：图片数量、检测数量、类别、最高置信度、推理时间。
   - 植被流程记录：植被覆盖率、阈值、覆盖图。
   - 专用标注数据到位后，再补充 Precision、Recall、mAP、mIoU。

4. 对接系统展示
   - AI输出字段包括：类别、置信度、检测框、结果图路径、植被覆盖率。
   - Web页面优先展示结果图、检测数量、类别统计和覆盖率。

## 每周安排

### 9.1-9.7

- 跑通批量实验脚本。
- 检查现有图片和A的数据集交付状态。
- 产出第一份批量实验记录。

交付物：

- `AI/runs/batch_experiments/EXP-YYYYMMDD-BATCH-V1/summary.csv`

- 失败案例截图

2. 通用YOLO模型只能证明流程，不能证明森林虫害/植被专用识别能力。
3. 论文所需实验必须保存数据版本、参数、指标和失败案例。
