## 已完成：Alpha Demo V0.1

本次完成了“训练模型 + 植被覆盖率 + Web 展示”的第一版联调。

### 后端接口

文件：`AI/api_server.py`

已完成：

- `/api/detect` 保留原图片上传识别功能。
- 本地存在 bootstrap 训练权重时，优先加载 `best.pt`。
- 权重不存在时，自动回退通用 YOLO 模型。
- 同一次图片上传中，额外计算 RGB ExG + Otsu 植被覆盖率。
- 返回植被覆盖率、植被像素数、总像素数、阈值和植被叠加图地址。

## 当前结论

AI Alpha Demo V0.1 已具备：

- 图片上传识别。
- 训练模型优先接入。
- 目标识别结果展示。
- 植被覆盖率展示。
