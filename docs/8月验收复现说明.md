# 8月验收复现说明

本说明用于让老师或队友快速复现 8 月 AI 模块 V1 的核心效果。

## 1. 启动本地 API 和网页

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe .\AI\api_server.py
```

打开浏览器：

```text
http://127.0.0.1:8000
```

接口文档：

```text
http://127.0.0.1:8000/docs
```

## 2. 验证图片识别 Demo

在网页中上传一张图片，点击识别。

预期结果：

- 页面显示识别目标数量。
- 页面显示结果图。
- API 返回 `detections`、`confidence`、`box` 和 `result_url`。

## 3. 验证训练模型是否已接入 Demo

打开：

```text
http://127.0.0.1:8000/api/health
```

如果本地存在训练权重，预期看到：

```text
model: best.pt
model_kind: bootstrap_tree_segmentation
```

如果没有训练权重，系统会自动退回通用模型：

```text
model: yolo26n.pt
model_kind: general_detection
```

## 4. 验证植被覆盖率流程

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe .\AI\vegetation_baseline.py tree.png --name EXP-20260815-01
```

预期输出：

- 植被覆盖率数值。
- `vegetation_mask.png`
- `vegetation_overlay.jpg`

## 5. 验证数据集检查

```powershell
.\.venv\Scripts\python.exe .\AI\dataset_check.py --data .\AI\config\vegetation_bootstrap_tree.yaml --strict
```

预期结果：检查通过。

## 6. 当前验收口径

可说：

> 8 月已完成 AI 模块 V1：图片输入、基础识别、植被覆盖率分析、结果保存、API 接口和 Web 展示链路均已跑通；同时完成 bootstrap 分割训练流程验证，产出初版权重并接入 demo。

不要说：

> 已完成可靠森林专用识别模型。

原因：当前模型仍依赖 bootstrap 伪标注数据，正式论文指标需要真实图片和人工标注数据。
