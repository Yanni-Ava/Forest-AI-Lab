# Web展示主线说明 V0.1

## 结论

项目展示主线采用：

```text
Vue前端 + FastAPI后端 + YOLO/植被分析模块
```

Streamlit 页面作为早期页面框架和成员阶段提交材料保留，不作为后续主线。

## 原因

Vue + FastAPI 更适合作为项目系统雏形：

- 前后端边界清晰。
- API 可同时服务 Web 页面、调试文档和后续硬件数据。
- 便于接入图片识别、传感器数据、历史记录和结果导出。

Streamlit 适合快速展示，但当前版本仅完成图片上传提示，尚未接入 AI 结果。
