8月阶段目标基本完成。

已完成最小工程闭环，AI 模块具备输入图片、执行识别/植被分析、保存结果和对外提供接口的能力。项目已具备进入 9 月“数据集 V2、模型优化、稳定实验流程”阶段的基础。

## 9月入口

9月应从以下任务开始：

1. 获取并检查 `dataset_v1`。
2. 用 `AI/dataset_check.py` 检查图片、标注、类别和训练/验证/测试划分。
3. 用 `AI/run_batch_experiment.py` 对森林图片批量生成结果。
4. 根据标注情况决定是否训练 AI模型V2。
5. 统一 Web 展示接口，以 Vue/FastAPI 方案作为主线，Streamlit 页面作为早期展示材料保留。
