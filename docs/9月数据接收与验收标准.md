# 9月数据接收与验收标准

负责人：王思丹  
适用对象：数据模块同学提交给 AI 模块的校园/森林图片数据

## 目的

本标准用于保证数据同学提交的图片能够直接进入 AI 训练流程，避免“图片收了很多，但不能训练”的情况。

## 数据同学需要提交什么

每批数据至少包含：

1. 图片文件。
2. 图片来源说明。
3. 图片清单表。
4. 是否允许用于项目展示的说明。

图片清单使用：

```text
AI/datasets/campus_forest_v05/metadata_template.csv
```

## 图片质量要求

合格图片：

- 能看清树、林地、草地或校园绿化。
- 主体与项目方向相关。
- 画面不过度模糊。
- 不全是天空、道路、建筑或人物。
- 有一定场景差异，例如远景、近景、不同光照、不同角度。

不建议使用：

- 纯风景天空图。
- 只有人物自拍、车辆、建筑的图片。
- 严重压缩、模糊、过暗或过曝的图片。
- 来源不清楚、版权不清楚的网络图。

## 数量要求

第一批建议：

- 总数：50 张以上。
- train：约 35 张。
- val：约 8 张。
- test：约 7 张。

更优目标：

- 总数：100 张以上。
- train/val/test 保持 70/15/15 左右。

## 命名规则

统一使用：

```text
CAMPUS_FOREST_0001.jpg
CAMPUS_FOREST_0002.jpg
CAMPUS_FOREST_0003.jpg
```

不要使用：

```text
微信图片_20260902.jpg
IMG_1234.jpg
截图1.png
```

## 负责人验收流程

王思丹收到数据后，按以下顺序处理：

1. 检查图片是否符合项目方向。
2. 检查图片来源是否记录清楚。
3. 按 train/val/test 分入 `campus_forest_v05`。
4. 使用 LabelMe 标注或安排人工标注。
5. 导出 YOLO segmentation 格式。
6. 运行数据集检查。
7. 训练 Alpha V0.5。
8. 与 V0.4 和当前 Demo 主模型对比。

## 自动验收工具

图片刚交付时，先运行：

```powershell
python .\AI\validate_campus_data_intake.py
```

它主要检查：

- 图片总数是否达到 50 张起步要求；
- 图片命名是否符合 `CAMPUS_FOREST_0001.jpg` 格式；
- metadata 表是否记录每张图片；
- 来源、地点/链接、授权说明是否缺失；
- train/val/test 比例是否接近 70/15/15。

图片标注完成后，再运行：

```powershell
python .\AI\dataset_check.py --data .\AI\config\campus_forest_v05.yaml
```

前者检查“数据能不能接收”，后者检查“数据能不能训练”。

## 批量整理工具

如果数据同学提交的是一个普通图片文件夹，先预览：

```powershell
python .\AI\prepare_campus_image_batch.py "D:\原始图片文件夹"
```

确认无误后正式复制：

```powershell
python .\AI\prepare_campus_image_batch.py "D:\原始图片文件夹" --copy
```

工具会完成：

- 统一命名；
- 自动划分 train/val/test；
- 更新 metadata 表；
- 保留原始文件名到 note，方便追溯。
