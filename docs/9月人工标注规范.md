# 9月人工标注规范

负责人：王思丹  
适用数据集：`vegetation_v2_public` 及后续校园/实地森林图片

## 标注目标

当前 Alpha 阶段先固定一个类别：

```text
0 tree
```

优先把树冠、树木主体和明显连续植被区域标成 `tree`。

暂时不做树种分类，也不做病虫害类别，避免 9 月任务发散。

## 标注边界

### 应该标

- 树冠区域。
- 连续树林区域。
- 明显绿色植被主体。
- 航拍/俯视图中的森林覆盖区域。

### 不应该标

- 天空。
- 云雾。
- 水面。
- 道路。
- 裸土。
- 建筑。
- 明显不是植被的阴影。

## 当前伪标注问题

从 `vegetation_v2_public` 的自动伪标注总览图看，主要问题有：

1. 雾天图片容易把雾和天空误标成植被。
2. 航拍图中裸地边界容易被误并入森林。
3. 自动生成的多边形边缘较粗，不适合直接作为正式论文标签。
4. 只靠颜色阈值无法区分“绿色植被”和“被雾/光照影响的背景”。

## 修标验收标准

一张图片进入正式训练前，需要满足：

1. 主要树冠/植被区域被覆盖。
2. 天空、云雾、道路、裸地没有明显误标。
3. 多边形边界不需要极细，但不能大面积越界。
4. 图片能通过 `AI/dataset_check.py` 检查。
5. 在 `metadata.csv` 或人工审核表中记录为 `human_checked`。
