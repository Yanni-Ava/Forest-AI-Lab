# 优秀结题风险与成果清单

## 主要风险

| 风险 | 预警信号 | 负责人 | 应对措施 |
|---|---|---|---|
| 航拍数据延期 | 两周内没有首批真实图片 | 成员A / 负责人 | 先采校园样例；明确每周交付数量 |
| 标注不一致 | 同类边界差异明显 | 成员A | 先标20张试标集并交叉复核 |
| 数据泄漏 | 相邻切片跨训练/测试集 | 负责人 | 按原始航拍任务分组划分；运行检查程序 |
| CPU训练过慢 | 单轮训练耗时无法接受 | 负责人 | 使用实验室或云端NVIDIA GPU；保存环境记录 |
| RGB无法计算NDVI | 相机没有近红外波段 | 项目组 | 改用可见光植被特征，材料中准确表述 |
| 缺少碳储量真值 | 只有影像、没有样地测量 | 全组 / 指导教师 | 尽早确定样地调查与经验参数来源 |
| 模型指标好但应用误差大 | mIoU提升而覆盖度误差不降 | 负责人 | 同时报告覆盖度和估算误差 |
| 专利创新不足 | 仅为常规模块组合 | 负责人 / 导师 | 先做现有技术检索，再确定交底点 |
| 成果无法复现 | 参数、代码、数据版本缺失 | 负责人 | 实验台账与版本门禁 |

## 月度管理门禁

每月底必须确认：阶段成果文件存在、负责人明确、验收人确认、风险更新、下一阶段入口条件满足。未通过门禁时优先补齐证据，不用新功能掩盖旧问题。
