# 论文实验设计草案 V0.1

## 论文依托方向

研究依托“基于无人机航拍图像的空地一体化森林碳汇监测系统”，不改变大创主线。AI论文部分聚焦无人机影像植被分割与空地数据融合对估算效果的影响。

## 候选题目

《基于无人机影像与地面环境数据融合的校园林地植被覆盖度及碳储量估算方法》

最终题目应在真实数据和实验结果明确后确定，不提前承诺“高精度”“实时”或具体改进模型名称。

## 研究问题

1. 深度学习分割相较ExG等传统RGB基线，能否降低阴影和复杂背景下的覆盖度误差？
2. 选择的单一模型改进点能否稳定提高小树冠或边界区域的分割指标？
3. 加入同时空地面环境数据后，碳储量估算误差是否降低？

## 实验组

- 传统基线：ExG + Otsu。
- 深度学习基线：YOLO轻量分割模型。
- 对比模型：选择1—2个同任务轻量分割模型。
- 改进模型：只保留一个有明确动机的主要改进点。
- 空地融合：影像单源估算与影像+地面数据估算对比。

## 数据设计

- 按原始航拍任务或区域划分训练、验证、测试集，不能随机混合相邻切片。
- 固定独立测试集，模型选择和阈值调整只使用验证集。
- 记录季节、天气、飞行高度、相机、区域和拍摄时间。
- 优先覆盖晴天/阴天、强阴影、不同植被密度和复杂背景。

## 指标与统计

- 分割：Precision、Recall、mAP50、mAP50-95、mIoU和各类别IoU。
- 应用：覆盖度平均绝对误差；有样地真值后计算RMSE、MAE和R²。
- 工程：参数量、模型大小、单张推理时间。
- 关键对比至少使用3个随机种子，报告均值与标准差；样本允许时增加显著性或置信区间分析。

## 论文证据链

每张论文图表必须关联：数据集版本、实验编号、代码版本、参数、指标文件和原始结果。禁止只保留截图或手工抄录指标。

## 停止规则

如果数据量、真值或实验效果不足，不强行撰写“模型改进”论文，可转向“低成本系统设计与校园林地实证”方向，保证结论真实可靠。
