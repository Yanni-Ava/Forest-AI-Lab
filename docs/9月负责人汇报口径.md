# 9月负责人汇报口径

## 30秒版本

我负责 AI 算法、Web 系统和项目管理。目前已经完成 9 月 AI Alpha Demo：系统支持图片上传识别、植被覆盖率计算和结果可视化展示。同时完成了多版 YOLO 模型训练对比，并建立了 LabelMe 人工修标到 YOLO 再训练的闭环。当前 Demo 保留稳定模型，后续会基于数据同学提交的真实校园/森林图片继续训练 Alpha V0.5。

## 1分钟版本

8 月主要完成了基础环境和图片识别 Demo。9 月我在这个基础上继续推进 AI Alpha 版本，重点做了四件事：

第一，完成 FastAPI 和 Vue 页面联调，上传图片后可以返回识别结果、植被覆盖率和可视化结果图。

第二，完成多轮模型训练，包括 bootstrap 模型、公开森林图片模型、筛选样本模型、自动修标模型、人工审核样本模型和 V0.4 修标模型。

第三，建立 LabelMe 修标流程，可以把 YOLO 标注转成可编辑 JSON，修完后再导回训练集继续训练。

第四，建立 campus_forest_v05 数据接收标准，后续数据同学提交真实校园/森林图片后，可以直接按规范进入标注和训练流程。

当前结论是：系统原型和模型迭代流程已经跑通，但正式高精度模型还需要更多真实图片和人工标注数据支撑。

## 被问“为什么不直接用最新模型”

可以回答：

最新 V0.4 模型已经跑通修标训练闭环，测试指标有提升，但由于样本量只有 10 张，默认预测阈值下还不够稳定。为了保证 Demo 展示可靠，目前主系统仍保留 bootstrap 模型，V0.4 作为模型优化实验记录。等 V0.5 使用真实校园/森林图片训练稳定后，再替换 Demo 主模型。

## 被问“你的工作和数据同学怎么区分”

可以回答：

数据同学主要负责收集和整理图片来源。我作为负责人负责制定数据能否进入训练流程的标准，包括命名、来源记录、train/val/test 划分、LabelMe 标注规范、数据集检查、模型训练和 Web 接入。也就是说，数据同学负责交付素材，我负责把素材转成可训练、可评估、可展示的 AI 模块。

## 被问“目前最大的不足”

可以回答：

目前最大不足是高质量真实标注数据还不够。我们已经通过公开图片和伪标注跑通了训练流程，也验证了数据质量对模型效果影响很大。下一步会重点补充真实校园/森林图片，并进行人工 polygon 精标，再训练 Alpha V0.5。

## 被问“这部分能不能支撑论文和软著”

可以回答：

可以作为基础支撑。论文方面，当前已经有数据集构建、标注质量控制、多版本模型对比和可视化指标记录；软著方面，系统已经具备图片上传、AI 推理、植被覆盖率计算、结果图生成和 Web 展示等功能模块。后续需要继续补充真实数据实验，使论文结果更扎实。
