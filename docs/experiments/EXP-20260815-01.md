# EXP-20260815-01：RGB植被覆盖率流程基线

## 基本信息

- 日期：2026-08-15
- 负责人：王思丹
- 目的：验证森林主题RGB图片的读取、植被像素提取、覆盖率统计和结果保存流程。
- 方法：Excess Green（ExG）可见光植被指数 + Otsu自动阈值 + 形态学处理。

## 环境与输入

- Python：3.12.10
- OpenCV：5.0.0
- NumPy：2.4.4
- 设备：AMD Ryzen 7 8745H，CPU
- 输入：`AI/input/tree.png`
- 图片尺寸：2160 × 1214

输入图是森林主题插画，不是真实无人机航拍图，仅用于流程验证。

## 运行命令

```powershell
python .\AI\vegetation_baseline.py tree.png --name EXP-20260815-01
```

## 结果

| 项目 | 数值 |
|---|---:|
| Otsu阈值 | 100 |
| 植被像素数 | 1,310,138 |
| 总像素数 | 2,622,240 |
| 植被覆盖率 | 49.96% |

结果文件：

- `docs/evidence/EXP-20260815-01/vegetation_mask.png`

## 结论与局限

程序已经形成“输入图片—生成掩膜—计算覆盖率—保存指标”的完整流程，可作为后续训练分割模型的工程基线。

该实验没有人工真值标注，因此不能计算Precision、Recall或IoU；ExG也不能区分树木与草地，且容易受到颜色、光照和阴影影响。本结果不是训练模型结果，不是标准NDVI，也不能用于论文精度结论。

下一步应由成员A提供真实航拍图和分割标注，建立 `dataset_v1`，再训练模型基线V1。
