# 校园 V0.5 训练与接入验收

日期：2026-09-05；负责人：王思丹。

## 数据与任务

本次实际读取项目执行目录 `03 数据集/已标注images/china_school_annotated_v0.5`，并非空的 `AI/datasets/campus_forest_v05` 模板。50 张照片来自可追溯的公开校园摄影资料，不是团队实拍；标签为模型辅助生成、AI复核，尚非独立人工真值。原始交付文件未修改。

逐一核对 50 张图及 50 张掩膜的 SHA-256、尺寸和像素类别；图片无完全重复，学校分组没有跨集合交叉。沿用交付划分：35 张训练、10 张验证、5 张困难保留测试。记录见 `AI/runs/campus_v05/data_audit.json`。

交付标签是语义掩膜，含孔洞和 255 忽略区域，不是单株实例多边形。因此本轮采用小型 U-Net 从零训练可见植被二分类，将 tree、low_vegetation、grass 合并，损失与评估均排除 255。保留现有 YOLO 目标检测链路；新增分割分支服务于原路线的植被参数展示。该模型不能输出单株数量、树种或碳储量。

## 实验配置

- CPU；随机种子 42；40 epochs；输入 192×192；batch 5；Adam，学习率 0.001。
- BCE + Dice loss；训练随机水平翻转；标签最近邻缩放。
- 仅依据验证集 IoU 选择权重，最终采用第 38 轮；保留测试集在选定权重后评估一次。
- 评估恢复至原图尺寸，0.5 阈值；IoU/Dice 累计有效像素，覆盖率 MAE 对逐图误差平均。
- 固定依赖见 `AI/requirements-ai.txt`。本机环境为 Python 3.12 与 CPU PyTorch。

这些是与辅助标签的一致性指标，不是独立人工真值准确率，不能与早先 YOLO 实例分割 mAP 直接比较。困难组仅 5 张，不能据此宣称广泛泛化能力或论文结论。

检查 U007 和 P001 四栏预览（原图、辅助标签、V0.5、ExG）：V0.5 连续冠层提取较完整，仍会把部分道路、屋顶误判为植被，边界较粗。未晋升为默认模型，作为网页可选择的试验版本。

## 复现及展示

```powershell
python AI/campus_v05.py --source "你的china_school_annotated_v0.5目录" --output "AI/runs/campus_v05_repeat" --epochs 40
python AI/check_alpha_acceptance.py
python -m uvicorn AI.api_server:app --host 127.0.0.1 --port 8001
```

训练脚本拒绝覆盖已有 best.pt；重复试验使用新输出目录。当前接入权重固定在 `AI/runs/campus_v05/best.pt`，训练记录为同目录 `report.json` 与 `history.csv`。以上检查脚本要求前端已经构建、接入模型训练完成；失败返回非零退出码。

网页选择“校园 V0.5 训练模型（试验版）”再上传图片。接口：`POST /api/detect?vegetation_method=campus_v05`。默认仍为 baseline。目标框来自原 YOLO 分支，植被比例和绿色叠加图来自所选植被算法，两者职责不同。
