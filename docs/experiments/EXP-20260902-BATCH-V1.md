# EXP-20260902-BATCH-V1

## 实验目的

验证9月AI批量实验流程是否可运行，并形成可复现的结果记录。

本实验不作为最终森林专用模型效果证明，只用于证明：

- 图片批量输入可用。
- YOLO通用检测结果可批量保存。
- RGB植被覆盖率基线可批量计算。
- 每张图片的结果可汇总到CSV和JSON。


## 输出文件

- `summary.csv`：每张图片的检测数量、类别、最高置信度、植被覆盖率和结果图路径。
- `details.json`：完整实验配置、每张图片检测框和植被结果。
- `annotated/`：YOLO检测结果图。
- `vegetation/`：植被覆盖率叠加图。

## 阶段结论

批量实验流程已跑通，可以支撑9月AI实验记录。

当前通用YOLO模型可以证明“图片输入、模型推理、结果保存”的工程流程，但不能证明森林虫害、树种或植被专用识别能力。后续必须接入 `dataset_v1` 或自建森林图片数据，才能进入正式AI模型V2训练与评价。
