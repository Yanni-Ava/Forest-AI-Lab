# 0902 LabelMe 人工精修任务包

## 本次产出

本次将人工审核种子集的 YOLO 分割标注导出为 LabelMe 可编辑 JSON，用于下一轮人工精修。

## 文件位置

- 标注任务目录：`AI/annotation_tasks/vegetation_alpha_v04_labelme`
- 训练集任务：6 个 JSON
- 验证集任务：3 个 JSON
- 测试集任务：1 个 JSON
- 合计：10 个 JSON

## 为什么需要这一步

前几轮实验表明，自动生成或半自动筛选的公开样本标注仍存在边界粗糙、误包含背景、漏标树冠等问题。直接继续训练容易把错误标注继续放大。

因此，本阶段先把标注转成可视化可编辑格式，便于人工修正后再导回 YOLO 数据集训练。
