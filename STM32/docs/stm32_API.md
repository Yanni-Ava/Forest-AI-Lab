# STM32 传感器数据串口接口协议 V0.1

## 目的
本协议定义成员B的 STM32 模块与 Web/系统模块之间的数据边界。
STM32 负责采集地面环境数据，通过串口以 JSON 格式发送；
Web/系统模块负责接收并解析。

## 接口类型
- 接口：USART1
- 波特率：115200
- 数据位：8
- 停止位：1
- 校验位：无
- 发送频率：每 500 毫秒一次

## 标准输出
{"temperature_c":25.5,"humidity_pct":60.0,"light_lux":1000.0}

每帧以 \r\n 结尾。

## 字段说明
|       字段名         | 类型  |  单位  |     说明    |
|--------------------|-------|--------|------------|
| temperature_c   | float |    °C   |     温度    |
|   humidity_pct    | float |    %    | 相对湿度 |
|       light_lux       | float |   lux   | 光照强度 |

## 错误约定
- 传感器读取失败时，对应字段输出 0.0
- 串口断开时，不发送数据

## 版本原则
- 增加字段保持兼容
- 删除或重命名字段需双方确认并提升版本号
- 每个数据帧必须包含完整的三个字段

## 联调样例
正式联调前，由成员B提供一组固定输出样例：
{"temperature_c":25.0,"humidity_pct":60.0,"light_lux":1000.0}
