# 植被分割数据集约定

成员 A 交付的数据集统一放在本目录，原始数据不要直接提交 Git。

## 建议类别

- `tree`：乔木树冠区域。
- `grass`：草地及低矮连续植被。
- `bare_land`：裸土、裸露地表。
- `other`：建筑、道路、水面及无法确定区域。

## 标注格式选择门禁

正式大量标注前先完成20—50张试标图：树冠等可分离对象可使用YOLO多边形实例标注；草地、裸地等连续覆盖区域更适合逐像素语义分割掩膜。负责人和成员A检查试标效果后确定最终格式，不能在格式未确认时批量标注。

以下结构是当前YOLO分割基线V1的交付结构；如果论文主模型改为语义分割，应另建像素掩膜版本并保留映射脚本。

## YOLO分割基线交付结构

```text
datasets/vegetation_v1/
├─ images/
│  ├─ train/
│  ├─ val/
│  └─ test/
├─ labels/
│  ├─ train/
│  ├─ val/
│  └─ test/
└─ data.yaml
```

建议按照 `70% / 20% / 10%` 划分训练集、验证集和测试集。同一张原始航拍图切出的相邻小图必须放在同一个子集，避免数据泄漏。

## 标注规则

1. 使用多边形标注可见植被边界，不用矩形框代替分割标注。
2. 阴影中的植被仍按真实类别标注；无法判断时标为 `other`。
3. 树冠与草地重叠时优先标注可见的上层树冠。
4. 不把图片边缘、压缩噪声或模糊区域强行标成植被。
5. 每批标注先抽查 10%，类别和边界规则一致后再继续。

## 数据台账

每批数据至少记录：来源、拍摄时间、地点、相机类型、飞行高度、分辨率、天气、授权状态、原始图数量、切片数量和标注负责人。
