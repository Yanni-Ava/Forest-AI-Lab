# Dataset Card: campus_forest_v05

## 数据集名称

campus_forest_v05

## 项目阶段

9 月 Alpha V0.5 数据准备阶段。

## 数据目标

用于训练森林/校园植被区域识别模型，重点支持：

- 树木/植被分割；
- 植被覆盖率估计；
- Web Demo 可视化展示；
- 后续论文实验数据积累。

## 数据来源

优先使用团队自行拍摄的校园或林地图片。补充公开图片时必须记录来源链接和授权说明。

## 标注方式

使用 LabelMe 进行 polygon 标注，标签统一写：

```text
tree
```

标注完成后通过项目脚本导回 YOLO segmentation 格式。

## 质量要求

- polygon 应尽量贴合树冠、树干、灌木、草地等植被区域。
- 不应将天空、水面、道路、建筑、人物作为植被标注。
- 对边界不清晰的远景森林，可以标注整体林地区域，但需避免大面积天空。
- 测试集图片不得参与训练和调参。
